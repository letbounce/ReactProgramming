# Прототип ІС КП "TroyBus" - Управління дорожніми листами

## Опис

Інтерактивний прототип інформаційної системи для управління дорожніми листами міського транспорту. Система реалізована за трирівневою архітектурою (Client-Server) та включає модулі для роботи з дорожніми листами, графіками маршрутів, рейсами та звітами по паливу.

## Структура файлів

```
prototype/
├── login.html              # Форма авторизації (LoginForm)
├── index.html              # Головна сторінка (дашборд)
├── daily-schedule.html     # Розклад руху (DailyScheduleView)
├── waybill-form.html       # Форма дорожнього листа (WaybillForm)
├── waybill-view.html       # Перегляд дорожніх листів (WaybillView)
├── fuel-report.html        # Форма звітів по паливу (FuelReportForm)
├── styles.css              # Стилізація
├── script.js               # JavaScript функціональність
└── README.md               # Документація
```

## Архітектура системи

### Client Tier (Boundary Classes)
- **LoginForm** - Авторизація користувачів
- **WaybillForm** - Введення та редагування дорожніх листів
- **WaybillView** - Перегляд дорожніх листів
- **DailyScheduleView** - Розклад руху
- **FuelReportForm** - Генерація звітів по паливу

### Application Server Tier (Control Classes)
- **WaybillController** - Обробка дорожніх листів
- **ScheduleController** - Управління розкладом
- **ReportController** - Генерація звітів
- **AuthController** - Авторизація

### Data Tier (Entity Classes)
- **Waybill** - Дорожній лист (fuel_level, mileage, route_schedule_id)
- **RouteSchedule** - Графік маршруту
- **Trip** - Рейс
- **ScanCopy** - Скани документів
- **User** - Користувачі (login, password_hash, role)

## Функціональність

### 🔐 Авторизація (login.html)
- Введення логіну та пароля
- Вибір ролі (Диспетчер/Водій)
- Перенаправлення за ролями

### 📅 Розклад руху (daily-schedule.html)
- Перегляд графіків маршрутів (RouteSchedule)
- Деталізація рейсів (Trip)
- Статистика розкладу
- Експорт розкладу

### 📝 Дорожній лист (waybill-form.html)
- Введення основної інформації
- Управління паливом (fuel_level) та пробігом (mileage)
- Прив'язка до графіку маршруту (route_schedule_id)
- Додавання рейсів (Trip)
- Завантаження сканів документів (ScanCopy)
- Автоматичні розрахунки

### 👁️ Перегляд дорожніх листів (waybill-view.html)
- Таблиця всіх дорожніх листів
- Детальний перегляд
- Фільтрація та пошук
- Статистика
- Друк дорожніх листів

### 📊 Звіти по паливу (fuel-report.html)
- Генерація звітів за період
- Фільтрація за маршрутом, транспортом, водієм
- Експорт у різних форматах (PDF/Excel/CSV)
- Попередній перегляд
- Метрики та статистика

## Запуск прототипу

1. Відкрийте файл `login.html` у веб-браузері
2. Введіть облікові дані та оберіть роль
3. Використовуйте навігаційне меню для переходу між розділами
4. Всі інтерактивні елементи працюють (модальні вікна, форми, таблиці)

## Ролі користувачів

### Диспетчер
- Доступ до всіх функцій системи
- Створення та редагування дорожніх листів
- Управління розкладом
- Генерація звітів

### Водій
- Створення дорожніх листів
- Перегляд своїх дорожніх листів
- Введення даних про паливо та пробіг
